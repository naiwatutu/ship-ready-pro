## 🎯 解决了哪些人群的什么核心痛点？

本工具专为**多 SKU、多品牌、多渠道（自主经销 + OEM/KA 定制）**的消费品与制造企业打造，精准解决四类人群的日常痛点：

| 目标人群 | 过去面临的痛点 | 本工具提供的解决方案 |
| :--- | :--- | :--- |
| **销售内勤 / 运营专员 / 数据分析** | 每月需从 ERP 导出多张发货明细手动透视、VLOOKUP 对齐商品编码；跨表公式经常出现 `#REF!` 报错；表里满屏 `0` 值干扰视线；修正数据重跑容易重复建列；历史原表归档全靠手动拖拽。 | **全自动幂等合并引擎**：自动识别表内日期月份、跳过尾部空列、同月重跑自动原位覆盖、0 值自动转空白（`None`）、自动刷新全年求和公式，并自动完成总表快照备份与原表归档。 |
| **产品研发 / 品牌与渠道经理** | 几百个 SKU 混在一起看不过来；新品上市后缺乏持续追踪，不知道哪款在连续爬坡、哪款首单后断货；想长期盯几款核心单品，每次都要手动拉历史数据画折线图。 | **新品 Cohort 洞察 + 选单式核心品追踪**：自动分层统计“当月首发 + 近 3 月次新孵化池”，输出 4 维新品趋势诊断；出报告前自动弹出编号清单，勾选后持久记住名单并自动生成多月走势曲线。 |
| **部门总监 / 总经理（管理层）** | 传统月报只罗列“本月卖了多少、环比涨跌多少”的流水账，看不出业绩下滑到底是销量跌了还是低价品拉低了均价，也看不清是哪个大客户阶段性停采导致的。 | **快消专业归因模型**：内置 **Revenue Bridge 营收桥接瀑布图**、**PVM 量价拆解**、**客户集中度 CR3/CR5/HHI 风控**与**连续 3 月零动销僵尸 SKU 清退清单**，直接给出经营决策依据。 |
| **AI Agent 玩家（Workbuddy / Claude Code / Cursor）** | 传统脚本把品牌和分类规则硬编码在代码里，业务一变就得改代码；依赖 `input()` 交互弹窗导致后台无头调度永久卡死。 | **数据驱动 + 无头双模调度**：运行时直接从总表自学习品牌与品类词典（零硬编码）；默认仅合并数据不污染总表，支持 `--preview` 预检选单与 `--report-only` 随时按需补出任意格式报告。 |

## ✨ 核心功能全景

### 1. 智能数据合并与总表保护机制
* **三级智能月份感知**：命令行参数 `--month` > 发货表内部日期区间（如 `2026-10-01`）> 文件名月份自动推断，彻底告别弹窗手输。
* **同月幂等原位覆盖**：自动检测总表是否已存在当月列——首次运行在末尾新增列，同月修正重跑自动原地覆盖更新，绝不重复建列。
* **纯数值固化与 0 值留白**：写入纯数值杜绝跨表 `#REF!`，0 动销单元格自动留空保持版面清爽，智能重构全年累计求和公式。
* **主表词典自学习（零硬编码）**：运行时扫描存量总表自动提取品牌与品类映射规则，仅需可选的轻量 `rules.json` 处理极少数同义词或独立子品牌拆分（如严格区分“天润一生缘”与“一生缘”）。
* **自动化闭环文件管理**：每次运行自动保存总表快照至 `02_历史总表备份/`，并将已处理的原始发货表移入 `01_已归档原表/`。

### 2. 专业快消经营分析模型
* **Revenue Bridge 营收桥接瀑布归因**：将上期到本期的营收净变动精确拆解为“首发新品增量 + 老品破零复采 + 在售品自然增长 + 在售品自然回调 + 本月断单/冲红”。
* **PVM 量价结构拆解**：分离“发货件数变动影响（Volume）”与“件均单价/产品结构变动影响（Price/Mix）”，精准定位波动主因。
* **新品专项与 Cohort 批次留存**：追踪近 N 个月上市批次的次月/三月动销留存率，自动识别“连续爬坡黑马”与“单点集中风险”。
* **选单式核心品月度持续追踪**：无需修改任何代码或配置文件，通过 `--preview` 查看编号清单并按编号/关键词勾选，自动持久化至 `watchlist.json` 并按月追踪。
* **全维度结构与风控**：支持多商业板块对比、全量赛道动态聚合、细分品类波士顿矩阵（BCG）、客户集中度 `CR3/CR5/HHI` 指数及连续 3 月零动销僵尸品预警。

### 3. 按需输出 4 种独立报告载体（绝不污染纯数值总表）
默认仅执行数据合并（`-f none`），需要汇报时可按需组合输出至 `03_月度分析报告/`：
* **`html`（ECharts 交互式 BI 驾驶舱）**：4 大板块 Tab 切换、瀑布图/双轴趋势图/环形图/折线图交互悬停、表格实时搜索过滤（请使用 Chrome / Edge 浏览器打开）。
* **`pptx`（咨询级高管汇报 PPT）**：自动生成每页结论型标题（Action Title），内置 240 DPI 高清图表、双量级分面折线图（防止低量级新品曲线被压扁）及自动换行防截断表格。
* **`xlsx`（财务级 4 工作表独立看板）**：拆分《总览与量价归因》《新品专项与留存》《核心品月度追踪》《僵尸品与冲红预警》，内置原生图表与条件格式色阶。
* **`md`（Markdown 经营简报）**：结构化纯文本与表格，适合直接复制发送飞书/企业微信/钉钉汇报或供大模型二次解读。
